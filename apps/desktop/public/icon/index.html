Folder structure

drop-in for the app repo
icon/ ├── README.md ← bundle instructions (icns / ico) ├── master/ ← vector source of truth │ ├── bridge.full.svg currentColor — inline this in app code │ ├── bridge.full.light.svg #F0EDE5 fill — for dark-mode export │ ├── bridge.full.dark.svg #2A2A26 fill — for light-mode export │ ├── bridge.simple.svg no hangers — for ≤24px │ ├── bridge.simple.light.svg │ ├── bridge.simple.dark.svg │ ├── bridge.tile.svg squircle + bridge — installer / About │ └── bridge.mask.svg white silhouette — tray template └── png/ ├── light/ → dark-mode dock / title bar │ └── bridge-{1024,512,256,128,64,48,32,24,16}.png ├── dark/ → light-mode dock / title bar │ └── bridge-{1024,512,256,128,64,48,32,24,16}.png ├── tile/ → installer / About / App Store │ └── bridge-tile-{1024,512,256,128,48}.png └── mask/ → tray / menu-bar template └── bridge-mask-{512,256,128,64,32,16}.png
Bundling step lives in icon/README.md. The browser sandbox can't produce .icns / .ico directly, so the README has the iconutil + magick one-liners you need on your dev machine. Once those run, drop the resulting bundles into icon/bundles/ and wire them into electron-builder (or whatever you're using) via the snippet at the bottom of the README.

Re-export. Edit a master, then re-run the raster batches in Brand Icon A - Spec.html (or split out the three run_script blocks here into a standalone script). All 27 PNGs regenerate from one source.
